# Claim Boundary

This repository is an experimental mathematical research artifact for the
Prime Clock Angular Sieve.

It does not claim:

- a new theorem about prime gaps;
- a result about the Riemann hypothesis;
- a result about classical covering systems;
- a proof of the prime number theorem;
- a theorem extending Prime Reciprocal Covering artifacts;
- a proof of the Erdos-Kac theorem;
- a proof of Mertens' theorem;
- a peer-reviewed mathematical result.

The first checked claim is the model-internal identity

```text
D(n, 0) = omega(n)
```

under the documented half-open point-membership convention.

All angular Erdos-Kac, Mertens uncovered-measure, and random-control work starts
as experiment and conjecture support only.
