# PrimeClock Dynamics v0.2.0 Artifact Metadata

This directory stores the versioned public metadata for the v0.2.0
Fixed-Cutoff Foundation Artifact.

Canonical metadata files:

- `ARTIFACT_MANIFEST.json`
- `RELEASE_NOTES.md`
- `CITATION.cff`

The root-level files with matching content remain the public landing files for
the current release. This directory keeps the v0.2.0 metadata stable when later
versions are added.
