# Shrinking-Angle Gaussian Field Claim Boundary

Status: v1.1.0 public artifact claim-boundary note.

## Claims

PrimeClock Dynamics v1.1.0 records the following public-facing claim surface:

- the exact complete-CRT collision kernel for moving angles;
- complete-CRT kernel-conditioned finite-dimensional Gaussian convergence;
- the explicit zero-ray shrinking-angle Gaussian corollary;
- deterministic support checks for the collision-kernel computation.

The theorem is conditioned on convergence of the normalized collision-kernel
matrix. The zero-ray corollary supplies one concrete shrinking-angle family.

## Non-Claims

This public artifact does not claim:

- integer-time shrinking-angle transfer;
- diagonal shrinking-angle Angular Erdos-Kac;
- finite-beta Angular Kubilius Chaos;
- standard Gaussian Multiplicative Chaos;
- uniform-in-alpha convergence;
- a full Gaussian field theorem over all angles;
- a distance-only kernel theorem for arbitrary moving angle arrays;
- a diagonal Mertens uncovered-measure law;
- high-point or extremal asymptotics;
- prime-time trace theorems;
- DOI, Zenodo publication, posted preprint, or peer review.

Angular Kubilius Chaos is future work for v2.0 or later. Mertens boundary and
high-point/extremal questions are reserved for later major-version tracks.
