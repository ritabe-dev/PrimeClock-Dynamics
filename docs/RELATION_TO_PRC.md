# Relation To Prime Reciprocal Covering

PrimeClock Dynamics is separate from the finite Prime Reciprocal Covering (PRC)
artifact repository.

PRC studies static finite CRT residue-covering artifacts. For a fixed residue
class `r mod M_k`, each old prime in a finite prefix contributes a closed arc
centered at `(r mod p)/p`. The public PRC repository is organized around finite
certificate artifacts, exact checks, and explicit release boundaries.

PrimeClock Dynamics studies the original time-dependent Prime Clock app model.
At integer time `n`, each active prime `p <= n` contributes an arc centered at
`(n mod p)/p`. The central object is the multiplicity field `D(n, alpha)` and
the uncovered measure `U(n)`.

The two projects are related through residue phases and circular arcs, but they
are not the same mathematical object. PrimeClock Dynamics is not a `v3.0` of the
PRC theorem release line.
